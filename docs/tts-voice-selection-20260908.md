## 接入边界

当前项目运行的是本地 vLLM-Omni S2-Pro。它通过本地已注册的参考音频使用 `voice` 名称，不能仅凭 Fish Audio 官网模型 ID 自动取得云端声纹。梓轩详情页当前显示暂无音频样本，因此没有把未经试听和授权的社区音色下载或伪装成本地声纹。

若要正式使用「梓轩」，需要在 Fish Audio API 账户具备授权后，通过官方 API 的 `reference_id` 调用，或取得允许本地部署的参考音频并用 `scripts/register_fish_voice.py` 注册。官方 API 文档说明，`reference_id` 是 Fish Audio 声音模型 ID，且预上传参考音频可改善质量并降低延迟：<https://docs.fish.audio/api-reference/endpoint/openapi-v1/text-to-speech>

在本地部署取得授权音频前，继续使用 `employee-natural`，确保当前会话不会因为声纹不存在而失败。完成注册后，只需将 `TTS_DEFAULT_VOICE` 和 `TTS_AVAILABLE_VOICES` 指向新的本地名称，再重新做固定文本、首音延迟、连续播放和 4 路并发验收。
